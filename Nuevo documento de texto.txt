# Instrucciones para reconstruir el proyecto

1. Instalar .NET 8 SDK
2. Instalar MAUI:
   dotnet workload install maui

3. Clonar este repositorio:
   git clone https://github.com/mcalistriraga/ProyAppMovil_MAUI_GestorProductos.git

4. Abrir el archivo MauiAppGestorMovil.sln con Visual Studio 2022+

5. Seleccionar Android o Windows como plataforma y presionar F5.
